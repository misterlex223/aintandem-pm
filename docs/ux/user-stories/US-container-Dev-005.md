## User Story

作為一個開發者，我希望能點擊一個按鈕就直接進入容器的 Shell 環境，以便我能快速進行除錯或執行指令。

## Acceptance Criteria

### Functional
- [ ] 列表中的每個「running」狀態的容器項都應有「進入 Shell」按鈕。
- [ ] 點擊按鈕後，應在瀏覽器中開啟一個功能完整的終端機介面，連接到該容器。

### Non-Functional
- [ ] Shell 介面應在 5 秒內載入完成並可供操作。
- [ ] 終端機介面的延遲應足夠低，以保證流暢的輸入體驗。
