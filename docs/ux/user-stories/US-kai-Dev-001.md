## User Story

作為一名開發者 (Alex)，
我希望能查看所有 Flexy 容器的儀表板，
以便我能快速了解現有環境的狀態並進行操作。

## Acceptance Criteria

### Functional
- [ ] 儀表板應顯示容器列表，包含名稱、狀態、ID 和掛載路徑。
- [ ] 應有按鈕可以「啟動」、「停止」、「刪除」容器。
- [ ] 應有按鈕可以導航至「Shell」和「Docs」(如果可用)。
- [ ] 應有一個「新增 Flexy」的入口點。

### Non-Functional
- [ ] 儀表板載入時間應少於 2 秒。
- [ ] 容器狀態應能接近即時地反映實際情況。
