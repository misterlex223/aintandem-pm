## User Story

作為一個開發者，我希望能從列表中刪除一個不再需要的 Flexy 容器，以便我能清理掉過時的開發環境。

## Acceptance Criteria

### Functional
- [ ] 列表中的每個容器項都應有「刪除」按鈕。
- [ ] 點擊「刪除」按鈕後，必須出現一個確認對話框，防止誤刪。
- [ ] 確認刪除後，該容器應從列表中移除。

### Non-Functional
- [ ] 刪除操作應在 10 秒內完成。
