## User Story

作為一名開發者 (Alex)，
我希望能在 UI 上快速建立一個新的 Flexy 容器，
以便為新任務設定一個乾淨的隔離環境。

## Acceptance Criteria

### Functional
- [ ] 「新增 Flexy」的介面應允許我輸入自訂名稱。
- [ ] 介面應提供一個主機目錄瀏覽器，讓我能輕鬆選擇要掛載的資料夾。
- [ ] 建立成功後，新的容器應出現在儀表板上。
- [ ] 如果建立失敗，應提供清晰的錯誤訊息。

### Non-Functional
- [ ] 建立容器的過程應在背景執行，不應鎖死 UI。
