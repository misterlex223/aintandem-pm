## Scenario: 進入容器進行除錯或操作

- **使用環境**: 在開發過程中，遇到需要直接在容器內部執行的操作時（例如：安裝套件、執行測試、檢查環境變數）。

- **行為動機**: 需要一個快速、直接的方式進入容器的 shell，而不需要透過 `docker exec -it ...` 等繁瑣的指令。

- **操作流程**: 
  1. 開啟 Kai Web UI。
  2. 在列表中找到需要進入的容器。
  3. 點擊該容器對應的「進入 Shell」按鈕。

- **預期成果**: 系統立即在新的瀏覽器分頁或當前頁面的內嵌視窗中，提供一個功能完整的 shell 終端機，並且已經登入到目標容器內。
