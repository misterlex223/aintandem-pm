## Scenario: 日常管理現有環境

- **使用環境**: 開發者在每日開始或結束工作時，在本地端電腦上操作。

- **行為動機**: 開始一天的工作時，需要啟動特定專案的容器環境；或在下班時，需要關閉容器以釋放系統資源。當某個專案徹底完成後，需要清理掉不再使用的容器。

- **操作流程**: 
  1. 開啟 Kai Web UI。
  2. 在容器列表中找到目標專案對應的容器。
  3. 點擊「啟動」按鈕以開始工作，或點擊「停止」按鈕以關閉它。
  4. 對於已完成的專案，點擊「刪除」按鈕，並在確認提示中點擊「確認」。

- **預期成果**: 容器的狀態在 UI 上立即更新。啟動、停止或刪除的操作在後端成功執行。
