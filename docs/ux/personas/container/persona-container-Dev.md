## Persona: 開發者 / AI 工程師

- **目標**:
  - 快速建立、啟動和進入 AI Agent (Flexy) 容器的開發環境。
  - 能夠輕鬆管理多個容器實例，而不需要記憶複雜的 Docker CLI 指令。
  - 將本地開發目錄無縫對應到容器中，以利程式碼同步與測試。

- **痛點**:
  - 手動管理多個容器的 port mapping 容易混亂且容易出錯。
  - 每次都需要透過 SSH 或複雜的指令才能進入容器的 shell。
  - 團隊成員之間的開發環境不一致，導致「在我電腦上可以跑」的問題。

- **技術背景**:
  - 熟悉軟體開發與 Git 版本控制。
  - 具備 Docker 基礎知識，但可能不精通所有進階指令。
  - 日常工作需頻繁使用終端機與 shell 環境。
