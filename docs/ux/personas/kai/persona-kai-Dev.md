## Persona: Alex (Developer / AI Engineer)

- **目標 (Goals)**: 快速建立、存取和管理用於 AI 輔助編碼任務的隔離開發環境 (Flexy 容器)，而無需處理複雜的 Docker 指令或端口衝突。

- **痛點 (Pain Points)**:
  - 手動管理多個 Docker 容器既繁瑣又容易出錯。
  - 在本機運行多個相同服務的實例時，經常遇到端口衝突問題。
  - 容易忘記用於掛載資料卷或設定網路的特定 `docker run` 參數。
  - 希望有一個簡潔的 Web 介面來管理這些環境，而不僅僅是依賴命令列。

- **技術背景 (Technical Background)**: 精通 Docker、Git 和多種程式語言。對使用 Web UI 和命令列工具都感到自在。
